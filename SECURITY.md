# Security Policy

> Language: **English** | [简体中文](SECURITY.zh-CN.md)

## Supported Versions

This is a private repository under active development. Security fixes are applied to
the latest commit on the default branch; no older versions are maintained.

## Reporting a Vulnerability

Do **not** open a public issue for security vulnerabilities. Report them privately:

1. Preferred: GitHub → **Security** → **Report a vulnerability** (private advisory)
   for this repository.
2. If that is unavailable, contact the maintainers privately through GitHub
   (profile contact options) and mark the subject as confidential.

Please include:

- the affected component and version (commit hash if possible);
- a description of the issue and its impact;
- steps to reproduce, or a proof of concept;
- any known mitigations or workarounds.

You will receive an acknowledgement as soon as practical. The maintainers will assess
the report, coordinate a fix, and credit reporters who wish to be credited. Reports
that turn out not to be vulnerabilities are handled the same way as ordinary bugs.
